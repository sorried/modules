# userbot modules

hello! this repository contains modules for telegram userbots using [telethon](https://github.com/LonamiWebs/Telethon) and [tgcrypto](https://github.com/pyrogram/tgcrypto).

## using a module

review each module's documentation for its requirements, configuration, and loading instructions. modules may depend on a specific userbot framework or version.

## contributing

- write module code and documentation in english.
- document the required dependencies, configuration, and setup for each module.
- run `ruff check .` and `python -m compileall -q .` before opening a pull request.
